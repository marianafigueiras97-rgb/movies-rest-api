# Movies API

API REST desarrollada con **Node.js, Express, MongoDB y Mongoose** como proyecto educativo para practicar la creación de servidores, el diseño de endpoints y la conexión con una base de datos NoSQL.

## Tecnologías utilizadas

* JavaScript
* Node.js
* Express
* MongoDB
* Mongoose

## Funcionalidades

La API permite realizar operaciones CRUD sobre una colección de películas:

* Obtener todas las películas.
* Obtener una película por su ID.
* Buscar una película por título.
* Buscar películas por género.
* Obtener películas estrenadas a partir de un año determinado.
* Crear nuevas películas.
* Actualizar películas existentes.
* Eliminar películas.
* Uso de semillas para insercción de datos masivos
* Gestión de errores y validaciones mediante Mongoose.

## Modelo de película

Cada película contiene información como:

* `title`
* `director`
* `year`
* `genre`

## Objetivo del proyecto

Este proyecto ha sido desarrollado con fines educativos para practicar:

* Creación de un servidor con Express.
* Creación y organización de rutas y controladores.
* Diseño de una API REST.
* Uso de métodos HTTP (`GET`, `POST`, `PUT` y `DELETE`).
* Conexión de Node.js con MongoDB.
* Creación de modelos y esquemas con Mongoose.
* Consultas y filtrado de documentos.
* Validación de datos.
* Gestión de errores y códigos de estado HTTP.

## Estado

Proyecto educativo completado como parte del aprendizaje de desarrollo backend con Node.js y bases de datos NoSQL.
